# Тортшер — демо одностраничного сайта

Неофициальная демо-версия сайта кофейни-кондитерской «Тортшер» (Тюмень), подготовлено InterPanic.

- Чистый HTML + CSS + JS, без сборки: `index.html`, `style.css`, `script.js`.
- Тексты, цены, адреса, логотип и фото взяты с https://tortsher.com/. Всё, чего на сайте нет, помечено `[УТОЧНИТЬ]`; отзывы — заглушки с пометкой «пример».
- Все права на логотип, фото и тексты принадлежат их владельцу. Страница закрыта от индексации (`noindex`).
